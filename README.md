# 🎮 Number Guessing Game (Java)

## 📌 Project Overview
This is a console-based Number Guessing Game developed using Java.  
The program generates a random number between 1 and 100, and the player must guess it within a limited number of attempts.

## 🚀 Features
✔ Random number generation (1–100)  
✔ Limited attempts (5 chances per round)  
✔ Score calculation based on performance  
✔ Feedback system (Too High / Too Low)  
✔ Option to play multiple rounds  
✔ Final score display  

## 🛠 Technologies Used
- Java
- Scanner Class
- Random Class
- Loops (while loop)
- Conditional Statements (if-else)

## 🎯 Game Rules
- The system selects a random number between 1 and 100.
- The player gets 5 attempts to guess the correct number.
- Points are awarded based on how quickly the number is guessed.
- The player can choose to play multiple rounds.
- Final score is displayed at the end of the game.

## 🧮 Scoring Logic
- More points are awarded for guessing in fewer attempts.
- Score increases based on:  
  `6 - attemptsUsed`
